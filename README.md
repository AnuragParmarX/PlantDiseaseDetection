# AI-Driven Plant Disease Prediction & Management System

An AI-powered web application that detects plant diseases from leaf images using Deep Learning. The system helps farmers and gardeners identify diseases quickly and provides treatment recommendations for better crop management.

---

## Features

- Upload a plant leaf image
- AI-based disease prediction 
- Displays predicted disease with confidence score
- Suggests treatment and prevention methods
- User-friendly web interface built with Flask
- Responsive design using Bootstrap

---

---


## How It Works

1. User uploads an image of a plant leaf.
2. The Flask backend preprocesses the image.
3. The trained model predicts the disease.
4. The application displays:
   - Predicted Disease
   - Treatment Recommendation
   - Prevention Tips
